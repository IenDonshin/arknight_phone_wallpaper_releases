# 方舟干员高清壁纸 · APK 发布

[下载最新版 APK](https://github.com/IenDonshin/arknight_phone_wallpaper_releases/releases/latest)

## 0.8.0 开发测试版

只使用高清完整立绘，删除普通卡面下载/显示与自动匹配。默认完整居中，按手机实际像素生成壁纸；保留手动拖动、缩放、保存及立即应用。“恢复默认居中”清除手动覆盖。原图完整保留，画面较宽可能有留白，人物偏位可自行调整。

覆盖升级后旧普通卡面缓存、旧匹配参数和 App 创建的普通卡面图库条目会清理。高清原图、手动位置和原壁纸备份保留；系统不允许删除的条目留待重试，不删除其他用户图片。

使用：森空岛登录并同步精二干员 → 选择候选 → 高清立绘下载与预览 → 下载所选高清 → 预览调整 → 保存并立即应用，或开启 15 分钟自动轮换。仅完整高清组参与，没有普通卡面回退。阿米娅仍只轮账号已解锁精二形态。

首次替换前需记忆原始静态壁纸，停止时恢复。每次打开检查 GitHub 更新，APK 保持同一签名可覆盖安装。图片源提供镜像和有限重试；最近下载日志单独保留，报错提交 GitHub Issue 需要登录。

97 项单元测试、构建/lint 与签名核验通过，真实手机效果和图库清理需要测试。

## 0.8.0 已拥有皮肤与阿米娅单周期

更新后先同步干员读取皮肤库存，再到高清下载页点“选择桌面立绘”。普通干员默认精二，可固定选一套已拥有皮肤；一个干员拥有多套时全部列出，锁屏仍用初始原图。新选择需先下载，手动取景分别保存。

阿米娅取消三倍时长，可固定已解锁精二形态或已拥有皮肤；不指定时随机一张合法已下载候选，每次仅一个周期。各游戏角色选择独立，未拥有皮肤不提供，库存未确认时提示并仅保留精二选项。

97 项单元测试及构建/签名核验通过，真实手机库存和效果需测试。全部使用静态高清原图，继续保留默认居中、手动调整、立即应用与停止恢复原壁纸。
