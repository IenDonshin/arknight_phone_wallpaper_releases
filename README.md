# 方舟干员壁纸 · APK 发布

[下载最新版 APK](https://github.com/IenDonshin/arknight_phone_wallpaper_releases/releases/latest)

支持 Android 8.0 及以上。此仓库用于公开发布签名 APK 和更新清单，源码仓库保持私有。

## 0.5.0 开发测试版

- 独立手机登录页直接展开鹰角官方验证码/密码登录组件，授权后自动返回同步，无需寻找官网入口。
- 同步干员，严格筛选账号已精二干员作为轮换候选，并支持勾选。
- 每个角色独立保存候选选择和干员缓存，失败保留上次完整同步结果。
- 每次打开 App 检查 GitHub 更新，确认后下载、校验并打开系统安装器。
- 自动区分账号凭证、签名过期和时间校验错误，支持按需刷新签名及有限重试。
- 修复 Android 与官网 JSON.stringify 的斜杠转义差异，避免设备标识含 `/` 时签名校验失败。
- 主屏幕和登录页提供“诊断日志”：可查看、复制，或打开预填 GitHub Issue 页面确认提交。
- 新增“卡面下载与预览”：下载已选组的初始和精二长方形 PNG，保存到 `Pictures/arknight_phone_wallpaper/`，支持缓存、暂停及失败重试。
- 阿米娅只使用账号已解锁精二形态，共用一张初始图，按术师、近卫、医疗整理一个轮换组；n 个形态对应 n 个普通周期。

已实现图片下载、预览、锁屏/桌面设置和自动轮换。64 项安卓单元测试、5 种登录流程测试、lint 与 APK 签名验证通过。阿米娅初始及三种精二真实卡面已通过 App PNG 校验器。手机图库、系统壁纸和后台任务仍需真机测试。

## 安装与测试

1. 在手机浏览器打开 Release，下载 `.apk` 文件；`update.json` 由 App 使用，无需手动下载。
2. 首次安装时按安卓提示允许浏览器安装应用。
3. 打开 App，点击“森空岛登录”，在自动展开的鹰角官方登录表单完成登录，随后自动进入干员同步；加载失败可点底部“重新打开登录”。
4. 检查已精二干员数量与实际账号是否一致；可点击角色名称切换官服/B服角色。
5. 后续新版使用相同 APK 签名，可覆盖升级保留本地数据。首次通过 App 更新时需在系统设置中允许本 App 安装 APK，并在系统安装器确认。

## 下载卡面

勾选候选组 → 卡面下载与预览 → 下载 / 补齐已选卡面。可预览并打开图库图片。原始游戏卡面通常是 180×360，不做放大或裁剪。取消勾选或退出账号不会删除已下载文件；阿米娅未解锁的形态不会下载。

登录凭证仅加密保存在本机，不需要提供 GitHub Token。退出账号会清除本机登录状态、干员缓存和候选选择。

## 手机报错

复现错误后点击“诊断日志”→“提交报错”。浏览器会打开公开仓库的 GitHub Issue 页面并预填近期日志；首次需要登录 GitHub，再确认提交。也可复制完整日志。记录保留最近 200 条，按字段白名单排除账号凭证、手机号、UID、账号昵称、干员明细、请求头、查询参数、响应原文和异常消息。

0.1.3 日志增加签名格式编号、设备标识长度与斜杠数量，便于排查编码问题，不记录设备标识或签名值。

## 自动切换壁纸

下载所选组后，打开“壁纸与自动轮换”，填写 15–10080 分钟并点开启。初始图设为锁屏，精二图设为桌面；每次完成后等待一个周期再切换，系统省电可能延迟。可以暂停或立即换下一张；手动切换会重新计时。阿米娅仅按账号已解锁的精二形态轮完，n 个形态共 n 个周期。

原图约 180×360，壁纸完整居中放大，透明及留白区域为深色，会有低分辨率模糊。默认不开启自动轮换，退出账号后暂停；暂停保留当前壁纸。强制停止 App 后需再次打开。

## 下次轮换倒计时

壁纸页面在当前状态下面显示每秒更新的 HH:MM:SS 倒计时，来自系统任务已保存的下次计划时间。重新进入页面不会从头计时；从 0.3.x 升级需重新开启一次。开启、修改间隔或立即换下一张后重新计时；暂停显示已暂停。到时尚未执行显示“已到计划时间，等待系统调度”，执行时显示正在切换。

## 0.4.0 系统定时切换

改用单个系统精确闹钟，直接唤醒切换本地壁纸，再安排下一周期；不需要常驻服务。默认间隔 15 分钟。

覆盖升级后，请进入壁纸页面，设置 15 分钟并点“开启 / 更新间隔并立即切换”，按引导允许“设置闹钟和提醒”，返回 App 完成开启。旧版后台任务已暂停，登录和已下载卡面保留。

按 Home 返回桌面，保留后台，观察第 15、30、45 分钟是否更换，再测试锁屏。日志中应出现 WALLPAPER_ALARM_FIRED 和 WALLPAPER_APPLY_FINISHED。尚需 OnePlus API 36 真机确认后台行为。暂停和手动换图继续可用，阿米娅仍按已解锁精二形态轮完。

## 0.5.0 高清立绘

卡面页新增“下载高清立绘并匹配卡面”。下载完整原图，用原始卡面中的人物自动定位缩放和位置，壁纸保留高清背景。完整原文件不裁切，保存到 Pictures/arknight_phone_wallpaper/FullIllustrations/；可打开原图或预览手机取景。

下载完后在壁纸页点“立即换下一张”测试，自动轮换也会优先使用已准备的高清定位。未下载高清的干员仍用原卡面；匹配不足会提示并完整居中显示。阿米娅只使用账号已解锁形态，15 分钟系统定时逻辑延续 0.4.0。

三个真实立绘样例通过匹配测试；原图整体尺寸不代表人物局部像素，清晰度因干员而异，手机实际显示需要测试。
